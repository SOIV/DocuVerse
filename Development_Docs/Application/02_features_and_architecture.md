# DocuVerse 앱 아키텍처와 기능 후보

현재는 설계 단계다. 아래 항목은 구현 완료 목록이 아니며 기본 경험·후속 모듈·보류 후보를 포함한다. 초기 범위와 완료 기준은 [앱 로드맵](05b_roadmap_and_future.md)을 따른다.

## 1. 프로그램 아키텍처

에디터 라이브러리 관련 문서: [Editor Library](../Editor_Library/)

셀프호스팅 웹 사이트의 구성과 실행 방식은 [프레임워크 문서](../Framework/README.md)에서 별도로 다룬다. 아래 앱 기능에는 장기 후보가 포함되며 프레임워크 초기 범위를 의미하지 않는다.

### 태블릿 우선 애플리케이션

- **우선 플랫폼**: iPadOS와 Android 태블릿
- **공통 기반**: 에디터·문서 로직을 공유하고 터치·펜 입력, UI, 저장소는 플랫폼별 어댑터로 연결
- **구현 방식**: 네이티브·WebView 등 구체적인 기술은 입력·편집 검증 후 결정
- **성능 목표**: 대규모 문서의 편집·표시에서도 입력 응답성을 유지하도록 검증
- **모듈식 설계**: 기능별 모듈화로 사용자가 필요한 기능만 활성화 가능

### 데스크톱 확장 후보

- Windows·macOS 앱의 제공 여부는 미정
- 기존 Electron 기반 데스크톱 구상과 Linux·CPU 아키텍처별 지원은 후속 검토 후보로 유지
- 웹 사이트 지원과 데스크톱 앱 지원 여부는 구분하여 관리

### 저장·서비스 책임

공통 문서 모델의 원본 보존·스키마 버전·첨부 참조는 에디터와 공유하고, 파일 접근·저장·검색·백업은 앱 호스트가 담당한다. 로컬 편집·저장에는 계정·클라우드를 요구하지 않는다.

저장 경로는 로컬, 플랫폼에서 검증한 외부 파일 제공자·클라우드 저장소, 후속 공식 클라우드로 구분한다. 동기화 폴더 접근·자동 병합·실시간 협업이 모든 태블릿에서 동일하게 작동한다고 가정하지 않는다.

동기화·백업·마이그레이션·기기 범위는 [저장·플랫폼 문서](05a_sync_and_performance.md), 공식 클라우드의 제한·구독 초안은 [사업 모델](04_business_model.md)에서 관리한다. 구체적인 클라우드 사업자·암호화·분산 서버 기술은 검증 후보이며 정적 사이트와 로컬 앱의 필수 구성이 아니다.

## 2. 기능 목록과 적용 범위

### 인증 및 계정 관리 — 후속 온라인 기능

공식 클라우드·외부 서비스 등 계정이 필요한 기능에만 적용한다. 플랫폼별 인증·권한·서비스 제공 조건을 검증한다. 실제 공유 규칙은 [확장·협업 문서](03_extensibility_and_collaboration.md)를 따른다.

1. **소셜 로그인 통합**
   - Google 계정 연동
   - Apple 계정 연동
   - GitHub 계정 연동
   - 사용자 인증 정보 보안 강화
   - 개인정보 최소화 접근법

2. **계정 관리 시스템**
   - 사용자 프로필 및 설정 관리
   - 기기 접근 관리 및 로그아웃
   - 계정 연결 관리 (API 키, 서비스 연동)
   - 계정 보안 관련 알림 및 설정

### 인터페이스 및 UX — 태블릿 기본 경험과 후속 확장

1. **현대적 사용자 인터페이스**
   - 효율적인 패널 및 탭 시스템 (개발 도구 스타일)
   - 직관적인 블록 기반 에디터
   - 시각 모드 전환 (다크/라이트) 및 커스텀 테마 지원
   - 반응형 레이아웃으로 다양한 화면 크기 대응
   - 작업 모드별 레이아웃 프로필 지원 (글쓰기, 코딩, 연구, 지식맵 등)

2. **워크스페이스 관리**
   - 다중 작업공간 지원
   - 탭 기반 문서 편집
   - 분할 보기로 여러 문서 동시 작업
   - 사용자 정의 단축키 및 명령 팔레트
   - 다중 모니터·창 배열 프리셋은 데스크톱 앱 제공 결정 이후 검토

### 지식 관리 — 최소 검색·태그·백링크부터 검증

1. **연결된 지식 체계**
   - 양방향 링크 및 백링크 시스템
   - 그래프 뷰로 문서 간 관계 시각화
   - 태그 시스템 및 YAML 프론트매터 지원
   - 자동 링크 추천 및 관련 문서 표시

2. **검색 및 탐색**
   - 전체 텍스트 검색: 플랫폼별 구현을 검증하고 선택한다. Ripgrep은 가능한 환경의 후보이며 웹 정적 검색과 구분
   - 파일 내용 미리보기
   - 태그, 속성, 내용 기반 필터링
   - 최근 문서 및 즐겨찾기 관리

### 문서 작성 및 편집

기본 텍스트·이미지·필기·컬러·포스트잇·도형부터 검증한다. 수식·고급 표·데이터베이스·지도·외부 연동은 선택형 후속 후보이며, 에디터 세부 동작은 [에디터 기술 문서](../Editor_Library/1.%20editor-library-document.md)를 따른다.

1. **고급 블록 기반 에디터**
   - 위키 스타일 문법 지원으로 풍부한 표현력
   - 실시간 미리보기 및 양방향 편집
   - 문서 내 이미지, 파일, 미디어 임베딩
   - 코드 블록 구문 강조. 코드 실행은 별도 권한·실행 환경을 요구하는 후속 확장
   - 텍스트와 손글씨를 같은 문서 흐름 안에서 조합하는 하이브리드 편집

2. **특수 컨텐츠 블록**
   - 수학 식 (LaTeX) 지원
   - 시각화 도구 (다이어그램, 차트, 그래프)
   - 생산성 도구 (칸반 보드, 타임라인)
   - 구조화된 데이터 (데이터베이스, 테이블 뷰)
   - 컬러 블록 및 색상 스와치 표시
   - 포스트잇 스타일의 자유 배치 메모
   - 도형, 화살표, 템플릿 기반 레이아웃 요소
   - 지도 지원 (네이버 지도 또는 구글 지도)
      - 북마크·지도 표시 등 구현·검증한 기능 범위를 서비스별로 명시

3. **연동 블록/시스템 — 후속 공식·커뮤니티 모듈 후보**
   - 달력(구글 캘린더 등 외부 캘린더 서비스 연동 가능)
      - 왼쪽 상단에 별도 탭이 존재(피그마에 있는 왼쪽 상단에 있는 홈 버튼 같이)
   - 이메일(지메일, 네이버, 카카오, 도메인 등)
      - 기능 활성화시 동일하게 왼쪽 상단에 별도 탭이 존재
   - To-Do 리스트
   - 외부 서비스 위젯 및 임베드
      - Figma, Miro, Canva 등 디자인 도구 실시간 미리보기
      - CodePen, JSFiddle, Replit 등 라이브 코드 실행 임베드
      - Airtable, Google Sheets, CRM 등 데이터 소스 연동
      - 소셜 미디어 및 생산성 도구 링크 미리보기
   - 자체 미디어 플레이어
      - 업로드한 오디오/비디오를 문서 안에서 즉시 재생
      - 미니멀 바, 컴팩트 플레이어, 풀 플레이어, 사이드바 플레이어 등 UI 선택
      - 재생 속도, 북마크, 타임스탬프 기반 노트 연결 지원
      - 미디어 라이브러리, 태그, 썸네일, 메타데이터 관리

### 개인화·미디어 작업 — 후속 경험 후보

- 작업 컨텍스트·프로젝트별 문서 추천과 대시보드·워크플로우
- 시간 추적·목표 관리·집중 모드·뽀모도로 타이머
- 노트·스케치북·플래너·워크시트 템플릿과 그리드·라인·점선 배경
- 페이지·섹션 재정렬, 사용자 템플릿 공유와 선택적 내보내기
- 음성 메모·받아쓰기·화면 녹화·캡처, 필기 시점과 오디오·영상 타임스탬프 연결
- 미디어 플레이리스트·썸네일·메타데이터와 기기별 재생·저장 범위 검증

기본 미디어 삽입·필기와 구분하여 입력·저장·재생 동작을 검증한다. 고급 손글씨·수식·다이어그램 인식과 AR 주석은 보류·기술 검증 후보로 관리한다.

### 개발자 도구 — 코드 표시 외의 고급 기능은 보류 후보

1. **기본 개발자 도구 통합**
   - 인라인 코드 블록 지원
     - 다양한 언어 구문 강조(Syntax highlighting)
     - 에디터에서 사용하는 코드 스타일링 및 포맷팅
   - Developer Tools 지원
     - 기본적인 웹 개발 검사 도구
     - 간단한 요소 검사 및 속성 확인
     - 사용자 스크립트 및 스타일 테스트 환경
   - 향상된 디버깅 기능
     - 브레이크포인트 설정 및 조건부 중단점
     - 변수 검사 및 값 수정
     - 실행 흐름 제어(단계별 실행, 진입, 이탈)
   - 성능 분석 통합
     - 메모리 사용량 모니터링
     - 실행 시간 프로파일링
     - 병목 현상 감지 및 최적화 제안

2. **개발 플러그인**
   - 언어별 개발 환경 설정
   - 터미널 액세스
   - 빌드 및 테스트 통합
   - API 문서 연동
   - 소스 코드 버전 관리 (Git 통합)
   - 로컬 개발 서버 및 컨테이너 실행 지원
   - 데이터베이스 탐색기 및 쿼리 도구
   - 프로젝트 단위 가상 환경 관리

### 외부 개발 환경 연동 — 별도 기술 검증 후보

1. **코드 에디터 연결 후보**
   - 외부 코드 에디터와 API·확장 연결의 실현 가능성 및 대상 환경 검증
   - 코드 편집 및 문서 작성을 단일 환경에서 전환 없이 가능하게 함
   - 코드 블록에서 한 번의 클릭으로 전체 개발 환경으로 확장 가능
   - 인라인 코드와 개별 개발 환경 간의 동기화 메커니즘 구현

2. **코드-문서 자동 연결 시스템**
   - 코드 변경 감지 및 문서 자동 업데이트 워크플로우
     - 함수/클래스 주석 변경 시 관련 문서 업데이트 제안
     - API 변경 시 자동 문서 수정 알림
     - 깃 커밋 기반 문서 변경 추적
   - 코드에서 문서로, 문서에서 코드로 양방향 이동 기능
     - 함수 호출/정의 내비게이션(F12 스타일)과 유사한 문서 내비게이션
     - 코드 주석과 문서 간의 양방향 링크 유지
   - AI 기반 코드-문서 동기화
     - 코드 변경에 따른 문서 업데이트 자동 제안
     - 문서 변경에 기반한 코드 리팩토링 제안
     - 코드와 문서의 불일치 감지 및 해결 도구

### 다국어 지원 — 번역·검증 범위별 제공

1. 기본 지원 언어
   - 한국어·영어·일본어를 지원 목표로 두고 초기 제공 언어는 번역·UI 검증 후 결정
   - UI·도움말·문서의 번역 완료 범위를 각각 표시
   - 라이브러리 가이드도 실제 제공한 번역 범위를 명시

2. 언어 설정
   - 시스템 언어 자동 감지 및 적용
   - 사용자 정의 언어 설정 옵션
   - 문서별 언어 설정 가능 (다국어 문서 작성 지원)

### PDF 기능 — 후속 검증 후보

1. PDF 통합 기능
   - PDF 파일 뷰어 내장
   - 모바일 기기에서 펜 지원 메모 및 주석
   - PDF 텍스트 추출 및 검색
   - PDF와 문서 간 링크 및 참조 생성

2. PDF 고급 기능
   - OCR을 통한 이미지 PDF 텍스트 인식
   - PDF 주석 및 하이라이트 동기화
   - PDF 내용 기반 자동 태그 및 분류 제안
   - PDF 문서 자동 요약
