# DocuVerse 에디터 라이브러리 — 소개 초안

[한국어](readme_v2-ko.md) | [English](readme_v2.md)

현재는 기획·설계 단계다. 패키지·API·지원 플랫폼은 구현·검증 후 확정하며, 이 문서는 배포 완료 기능이나 실행 가능한 설치 안내를 의미하지 않는다.

## 목적

공통 문서 모델·편집 명령·변환·확장 규약을 독립 라이브러리로 제공한다. 공식 태블릿 앱과 셀프호스팅 문서 프레임워크가 같은 기반을 사용하며, 개발자는 에디터만 자신의 제품에 통합할 수 있다.

## 기능 구성

- 기본 문서·블록 스키마, 선택, 편집 명령, 실행 취소/다시 실행
- 선택형 Markdown·허용 HTML·나무위키 스타일 파서와 변환
- 기본 표와 후속 고급 표·수식·문법 확장
- 플랫폼별 입력·렌더링·클립보드·터치·펜 어댑터
- 편집 UI 없이 사용할 수 있는 읽기 전용 표시와 공통 데이터 처리 경계
- 문서 버전·확장 데이터 보존과 미지원 블록 대체 표시

각 문법·변환은 명시한 범위에서 검증한다. 필기·고급 블록까지 모든 텍스트 형식에서 손실 없이 왕복 변환된다고 보장하지 않는다.

## 앱·서버와의 경계

파일 저장·계정·워크스페이스 검색·문서 트리·공유·협업 서버는 호스트에서 담당한다. 협업 데이터 연결은 선택형 확장이며 기본 편집에 DB·인증·실시간 서버를 요구하지 않는다. 특정 UI 프레임워크나 외부 서비스도 코어의 필수 구성이 아니다.

ProseMirror 계열 엔진·UI 프레임워크·빌드 도구는 검증 후보다. 초기에는 iPadOS·Android 태블릿 편집과 웹 표시를 확인하고 실제 사용할 어댑터를 선택한다. 모든 플랫폼·버전 지원을 일괄 주장하지 않는다.

## 플러그인 호환

공통 로직과 환경별 UI·실행을 분리한다. 실제 테스트한 환경과 버전만 호환으로 표시하고, 플랫폼별 기능 소개·사용·결과 녹화와 공개 전 심사를 적용한다. 상세 기준은 [공통 정책](../../Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다.

## 라이선스 상태

MIT 배포는 에디터의 기존 기획 목표다. 현재 저장소의 [LICENSE](../../../LICENSE)는 GPL-3.0이며 별도 MIT 패키지가 이미 배포되었다는 뜻은 아니다. 패키지별 라이선스는 배포 전에 확정한다. 상태는 [공통 문서](../../README.md)에서 관리한다.
