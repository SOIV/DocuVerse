# DocuVerse 플랫폼별 테스트 환경과 기록

테스트 후보와 실제 검증 결과를 구분한다. 이 문서의 기기 목록은 테스트 완료·보유 기기·최소 사양 또는 출시 지원 목록이 아니다. 지원 OS·브라우저 버전은 테스트를 수행할 때 실제 버전을 기록하여 정한다.

플랫폼 태그·영상 업로드·편집 허용·공개 전 심사 기준은 [공통 정책](Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다. 같은 기준을 이 문서에서 중복 정의하지 않는다.

## 1. 우선순위

| 순위 | 대상 | 선정 방향 |
| --- | --- | --- |
| 우선 | iPadOS 태블릿 앱 | iPad 계열에서 화면 크기·키보드·펜 지원 차이를 확인할 대표 기기 선정 |
| 우선 | Android 태블릿 앱 | Galaxy Tab 등 펜 지원과 보급형·성능 차이를 확인할 대표 기기 선정 |
| 우선 | 웹 문서 프레임워크 | Safari·Chrome·Firefox·Edge 등 실제 지원하려는 브라우저와 정적 배포 환경 선정 |
| 필요 시 | 웹 편집·동적 서버 | 선택한 브라우저·런타임·저장소·인증 조합별 확인 |
| 후속 | iOS·Android 스마트폰 | 추가 지원 결정 이후 작은 화면·카메라·공유·음성 입력 확인 |
| 미정 | Windows·macOS 앱 | 앱 제공 여부 결정 이후 별도 테스트 |
| 후보 | Linux·추가 OS·CPU 환경 | 수요·실행 방식·검증 자원에 따라 결정 |

PC에서 웹 사이트를 확인한 결과와 PC용 네이티브·Electron 등의 앱을 확인한 결과는 다른 기록이다. WebView·브라우저·앱·시뮬레이터 결과도 각각 구분하며 시뮬레이터만 확인한 결과를 실기기 검증으로 표시하지 않는다.

## 2. 기능별 확인

### 에디터·태블릿 앱

- 키보드·한국어 IME, 터치·선택·클립보드·실행 취소/다시 실행
- 펜 입력·색상·압력·기울기·손바닥 방지 중 실제 구현한 기능
- 문서 저장·재열기·앱 중단·재시작, 미지원 블록·첨부 원본 보존
- 가로·세로·분할 화면·화면 배율·기본 테마·접근성
- 문서·미디어 규모별 반응성·메모리·배터리·백그라운드 제한

### 프레임워크·플러그인

- 편집 UI·동적 서버 없이 정적 빌드 결과를 제공하는 구성
- 동적 OFF에서 정적 대체·브라우저 로컬 기능만 작동하고 동적 API·외부 서비스 호출·작업이 실행되지 않는지 확인
- ON에서 선택한 기능의 인증·저장·오류·취소·권한 처리
- ON/OFF 전환·재시작 후 설정 유지와 데이터 보존
- 플러그인 등록·해제·업데이트·미지원 환경과 정적 대체의 실제 결과
- 동기화를 제공하는 경우 오프라인·불안정한 연결·충돌·접근 권한 해제

## 3. 기록 항목

| 항목 | 기록 내용 |
| --- | --- |
| 검증 대상 | 제품·플러그인 이름, 배포 버전 또는 소스 revision |
| 실행 환경 | 플랫폼, 기기 모델·실기기 여부, OS, 브라우저·WebView·서버 런타임 버전 |
| 호스트 | 앱·프레임워크·SDK·문서 규약 버전 |
| 구성 | 정적·동적 모드, 권한, 저장소·인증·외부 서비스 조건 |
| 사용 절차 | 설정·핵심 조작·입력 자료·기대 결과 |
| 결과 | 실제 결과, 정상·부분 지원·실패·미검증, 제한·재현 방법 |
| 근거 | 테스트 날짜, 플랫폼별 녹화 영상·구간, 심사 상태 |

실제 테스트 전에는 결과를 미검증으로 표시한다. 플랫폼 태그는 정상 작동의 근거와 영상이 해당 제출 버전에 연결되고 심사에서 확인된 범위에만 부여한다.

## 4. 녹화와 심사 연결

테스트 중 기능의 목적·설정·사용 절차·실제 조작·결과를 녹화하여 업로드한다. 정적 대체를 지원한다고 표시하려면 OFF 상태의 결과도 확인한다. 여러 환경을 한 영상에 담을 때는 각 구간의 플랫폼·버전을 구분한다.

편집 허용 범위와 오인·오류 은폐에 따른 거부·보완 요청은 공통 정책을 따른다. 기기·버전·기능이 달라지면 기존 태그를 자동 확장하지 않는다.
