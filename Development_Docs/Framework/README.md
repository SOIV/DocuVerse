# DocuVerse 셀프호스팅 문서 프레임워크

DocuVerse 프레임워크는 공통 문서·에디터 라이브러리를 바탕으로 문서 사이트와 위키를 만들고 직접 호스팅할 수 있도록 하는 개발 도구다. 준비된 사이트 구성을 사용하거나 필요한 라이브러리만 기존 웹 프로젝트에 통합할 수 있도록 설계한다.

현재는 기획·설계 단계다. 아래 문서는 구현된 기능이나 출시 일정을 보장하는 목록이 아니라, 제품 방향과 구현 시 지켜야 할 기준을 정리한다.
