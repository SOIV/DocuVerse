## 7. 구독 모델 및 수익화 전략

첫 운영시에 기본적으로 무료로 풀어두고 어느정도 가닥이 잡였다고 보여질때 정식 출시에 구독과 수익성을 추가하여 운영 시작.<br>
다만 Early Access 시기에 개발자 후원, 마켓플레이스 등 정도만 활성화

### 구독 등급 체계
1. **무료 플랜**
   - 기본 문서 편집 및 지식 관리 기능
   - 무제한 로컬 저장 기능
   - 외부 클라우드 폴더 기반 저장 무제한
      - OneDrive, Google Drive, iCloud Drive, Dropbox 등 사용자가 보유한 외부 저장소 활용
   - 자체 클라우드 업로드 및 백업은 문서 수량 또는 저장 용량 기준으로 제한
   - 제한된 공유 기능 (최대 4명과 공유 가능)
      - 사용자 추가/초대하여 공유, 협업 부분
      - 일반 링크 공유는 무제한
      - 자체 클라우드에 업로드하여 공유 가능한 문서 수량 제한
   - 기본 API 통합 (모든 외부 AI 서비스 API 사용 가능)
   - 개인 사용자 중심

2. **프로 플랜 (월 $9.99 또는 연 $99)**
   - 확장된 공유 기능 (최대 10명과 공유 가능)
      - 사용자 추가/초대하여 공유, 협업 부분
      - 일반 링크 공유는 무제한
      - 자체 클라우드 기준 공유 문서 수량 무제한 또는 사실상 무제한
   - 사용자 정의 도메인으로 문서 공유 가능
   - 고급 협업 기능 (댓글, 알림, 멘션)
   - 우선 지원 및 업데이트 (베타 기능 조기 접근)
   - 프로 전용 플러그인 접근권
   - 3개월 무료 체험판 옵션 (신규 사용자 대상)
   - 교육 플랜 (지정된 이메일로 무료 사용)
      - 대학교 및 학교에서 생성된 이메일로 가입 또는 기존 계정에 등록하여 사용
      - 기존 계정에 등록하여 사용할 경우 매년마다 인증 필요

3. **플래티넘(맥스) 플랜 (월 $19.99 또는 연 $199)**
   - 무제한 공유 및 협업 기능
   - 자체 클라우드 공유 문서 수량 무제한 또는 사실상 무제한
   - 고급 권한 관리 및 접근 제어
   - 플래티넘 전용 기능 및 테마
   - 최우선 지원 및 전용 포럼
   - API 접근 및 통합 기능

4. **팀/기업 플랜 (사용자당 가격)**
   - 중앙 관리 콘솔
   - 기업급 보안 및 규정 준수 기능
   - 전용 지원 매니저
   - 사용자 정의 통합 및 API
   - 교육 및 온보딩 지원

### 플랜별 기능 구분 초안
| 영역 | 무료 플랜 | 프로 플랜 | 플래티넘(맥스) 플랜 | 팀/기업 플랜 |
| --- | --- | --- | --- | --- |
| 문서/블록 | 기본 편집 및 로컬 저장 | 블록/차트/폼 등 고급 편집 확장 | 고급 검증 및 프리미엄 기능 | 조직 단위 관리 및 검증 |
| 로컬/외부 클라우드 저장 | 무제한 | 무제한 | 무제한 | 무제한 |
| 자체 클라우드 저장/백업 | 문서 수량 또는 용량 제한 | 한도 확장 | 무제한 또는 사실상 무제한 | 조직 정책 기반 확장 |
| 페이지 이력 | 단기 이력 | 확장 이력 | 장기 또는 무제한 이력 | 감사 로그와 장기 보존 |
| 공유/협업 | 공유 문서 수량 및 참여자 제한, 링크 공유 | 공유 문서 수량 무제한 또는 사실상 무제한, 댓글, 멘션 | 고급 권한 및 비공개 팀스페이스 | SSO, SCIM, 감사 로그, 관리자 제어 |
| AI | 기본 AI 연동 | 사용량 및 자동화 확장 | 고급 AI 기능 | 기업 통합 검색 및 조직 정책 |
| API/자동화 | 기본 API, 웹훅, 임베드 | 사용자 정의 자동화 및 통합 | 프리미엄 API 통합 | 고급 API 통합 및 관리 콘솔 |
| 웹 게시 | 기본 페이지 게시 | 사용자 지정 사이트/도메인 옵션 | 브랜딩 옵션 확장 | 조직 도메인 및 보안 정책 |
| 지원 | 커뮤니티 중심 | 우선 지원 | 최우선 지원 | 전담 지원 및 온보딩 |

위 표는 기능 묶음의 기준을 잡기 위한 초안이며, 실제 가격과 제한 수치는 운영 비용, 클라우드 저장 비용, AI 사용량 정책이 확정된 뒤 조정한다.

저장 과금 원칙은 단순 문서 작성과 저장을 막지 않는 것이다. 로컬 저장과 외부 클라우드 폴더 저장은 기본적으로 제한 없이 제공하고, 자체 클라우드의 공유, 협업, 권한 관리, 백업처럼 서버 비용이 발생하는 기능을 중심으로 무료 제한과 유료 확장을 둔다. 유료 플랜의 "무제한"은 비정상 사용 방지를 위한 공정 사용 정책을 전제로 한다.

### 할인 및 프로모션
1. **할인 및 프로모션 전략**
   - 할인 쿠폰 등록 기능
   - 다양한 프로모션 코드 지원
     - 3개월 무료 사용권(기간은 프로모션에 따라 다를 수 있음)
     - 특별 할인 코드(% 할인 방식)
     - 신규 사용자 Welcome 패키지
     - 리퍼럴 프로그램 할인
   - 계절별, 기념일 한정 프로모션

2. **추천 및 리퍼럴 프로그램**
   - 기존 사용자 추천 시 양측에 혜택 제공
   - 추천인에게 무료 프로 플랜 사용권
   - 피추천인에게 초기 할인 혜택

3. **콜라보, 이벤트**
   - 다른 업체와 콜라보 또는 이벤트
   - 컴퓨터와 관련된 장비나 그 외 여러가지

### 추가 수익 모델
1. **마켓플레이스**
   - 판매자 및 배포자의 개인 페이지 생성 가능
   - 개발자 수익 공유 모델 (80/20 or 90/10 분배)
   - 마켓플레이스에서 모든 유료 판매에 대한 제로 수수료(사용자 부담 X)
   - 프리미엄 플러그인 및 테마 판매
   - 템플릿 및 워크플로우 판매
      - 공식 템플릿 및 워크플로우 제공(무료/유로)
   - 커뮤니티 기반 생태계 구축

2. DocuVerse AI
   - 확정되지 않은 모델/기능
   - 자체 AI 시스템
   - 외부 AI에서 사용이 불가능한 기능 위주

3. 단일 후원(개발자에게 커피사주기)
   - 개발을 위해 일반 후원
