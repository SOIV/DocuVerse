# DocuVerse 공식 앱 개요

현재는 기획·설계 단계다. 기능의 초기 범위는 [앱 로드맵](05b_roadmap_and_future.md), 프로젝트 전체 제품 구성과 라이선스 상태는 [공통 문서](../README.md)를 따른다.

## 1. 제품 목적

DocuVerse 공식 앱은 Notion의 구조화된 문서·블록과 GoodNotes/Notability 계열의 필기·자유 배치 경험을 함께 다루는 하이브리드 노트 앱을 지향한다. 로컬 저장, 백링크, 태그와 데이터 이동성을 통해 사용자가 자신의 문서를 관리할 수 있도록 한다.

텍스트, 이미지·첨부 자료, 필기, 컬러 블록, 포스트잇 및 도형을 하나의 문서 흐름에서 사용할 수 있는 경험이 초기 검증 대상이다. AI·개발 도구·외부 서비스 통합은 이 기본 경험 위에 추가하는 후속 모듈이다.

## 2. 플랫폼과 제품 관계

- iPadOS·Android 태블릿을 우선 대상으로 한다. 터치·펜·키보드 입력을 실제 환경에서 검증한다.
- Windows·macOS 앱 제공 여부는 미정이며 Linux·스마트폰 등은 후속 검토 대상이다.
- 네이티브·WebView 등 구현 방식은 입력 품질과 성능을 검증한 뒤 결정한다.
- 독립 에디터 라이브러리와 공통 문서 모델을 사용하며 UI·저장소·계정·워크스페이스는 앱에서 담당한다.
- [셀프호스팅 프레임워크](../Framework/README.md)는 별도의 웹 게시·사이트 구축 도구다. 앱 사용에 사이트 운영을 요구하지 않는다.
- 프레임워크의 동적 기능 OFF가 앱의 로컬 편집·저장·필기를 비활성화하지 않는다.

## 3. 사용자 경험의 우선순위

1. 계정·클라우드 없이 로컬 문서를 작성·저장·다시 열 수 있는 기본 흐름
2. 텍스트와 필기·블록의 결합, 터치·펜 조작과 문서 탐색
3. 검색·태그·백링크를 통한 최소 지식 연결
4. 명시적인 가져오기·내보내기와 데이터 보존
5. 검증된 공식·커뮤니티 확장을 선택하는 경험

외부 API·클라우드·온라인 AI·협업은 네트워크와 별도 구성이 필요한 기능이다. 오프라인 사용은 로컬에서 제공 가능한 기능을 기준으로 하며 온라인 기능까지 모두 사용할 수 있다는 뜻은 아니다.

## 4. 확장과 호환

공식 기능은 기본 모듈 또는 선택형 플러그인으로 제공할 수 있다. 공식 관리 여부와 기본 탑재 여부는 별도로 결정한다. 앱·웹은 문서 데이터와 재사용 로직을 공유하되 모든 UI·OS 기능의 동일한 동작을 보장하지 않는다.

지원하지 않는 블록도 원본 데이터를 유지하고 대체 표시한다. 플랫폼·버전·기능·실행 모드의 호환 태그와 테스트 영상은 [공통 검증 정책](../Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다.

## 5. 후속 제품 방향

클라우드 백업·동기화·공유, 실시간 협업, 외부 API·다중 AI 제공자 커넥터, 미디어 라이브러리 및 개발자 문서화 도구를 후보로 둔다. 서비스별·플랫폼별 구현과 검증 결과에 따라 제공 범위를 정한다.

공식 클라우드의 구독·공유 제한은 [사업 모델 초안](04_business_model.md)에서 다룬다. 셀프호스팅 프레임워크의 라이선스·배포·운영 정책은 별도로 확정한다.

## 6. 참고하는 사용 경험

- Notion: 구조화된 문서·블록·데이터 보기
- GoodNotes/Notability: 펜 입력·필기·시각적 노트
- Obsidian: 로컬 파일·백링크·태그·데이터 이동성
- VSCode 계열 도구: 패널·탭·명령 탐색 등 인터페이스 구상

특정 제품과 기능·플러그인·데이터가 그대로 호환된다는 의미는 아니다. 고급 기능 후보는 [앱 기능 문서](02_features_and_architecture.md)에 정리한다.
