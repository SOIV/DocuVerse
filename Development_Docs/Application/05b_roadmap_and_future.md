# DocuVerse 앱 개발 범위와 로드맵

공식 앱은 iPadOS·Android 태블릿을 우선 대상으로 한다. Windows·macOS 제공 여부는 미정이며 구체적인 UI·네이티브/WebView 기술은 검증 후 결정한다. 기능 세부는 [앱 기능 문서](02_features_and_architecture.md), 공통 에디터와 웹 제품의 개발 순서는 [에디터 로드맵](../Editor_Library/editor-library_roadmap.md)과 [프레임워크 로드맵](../Framework/03_scope_and_roadmap.md)에서 관리한다.

기존 3~4개월 등 단계별 기간은 현재 제품 구성을 검증한 추정이 아니므로 확정 일정에서 제외한다. 인력·기술·기기 검증 범위를 정한 뒤 산정한다.

제품 간 우선순위·선행 조건·배포 판단은 [통합 로드맵](../ROADMAP.md)을 따른다. 아래 번호는 앱의 작업 묶음이며 최소 호스트·게시 연결은 로컬 MVP와 함께 검증하고 이후 확장할 수 있다. 프레임워크 전체의 완성을 앱 출시 조건으로 두지 않는다.

## 1. MVP 범위

초기 목표는 텍스트·블록과 필기를 함께 쓰는 하이브리드 노트 경험을 태블릿에서 검증하는 것이다.

- 공통 에디터를 연결한 기본 문서 작성·편집
- 계정·서버 없이 로컬 문서 작성·저장·재열기
- 텍스트·이미지·첨부 자료와 기본 미디어 표시
- 기본 필기·컬러 블록·포스트잇·도형
- 태그·검색·백링크 등 최소 지식 연결
- 원본을 보존하는 가져오기·내보내기와 미지원 블록 대체 표시
- 터치·펜·키보드·IME, 기본 테마·설정 및 태블릿 화면 대응
- 공통 확장을 연결할 최소 호스트 경계와 앱·웹 데이터 재사용 예제

초기 확장 경계는 MVP에서 정의하지만 마켓플레이스·모든 플러그인·계정·실시간 협업까지 필수 구현하지 않는다.

## 2. 제품별 작업 묶음과 완료 기준

| 묶음 | 결과물 | 완료 기준 |
| --- | --- | --- |
| 1. 입력·공통 모델 검증 | 최소 에디터·태블릿 어댑터·대표 문서 | iPadOS·Android 환경에서 입력·선택·IME·필기 구현 범위를 확인하고 저장·복원 |
| 2. 로컬 MVP | 기본 블록·문서 탐색·검색·태그·백링크·내보내기 | 계정·네트워크 없이 기본 작업 가능, 앱 재시작·미지원 블록에서도 데이터 보존 |
| 3. 확장·게시 연결 | 공개 확장 규약과 앱·웹 예제 | 공통 데이터·로직 공유, 플랫폼 UI 분리, 명시적 내보내기·가져오기로 웹 게시 검증 |
| 4. 선택형 온라인 서비스 | 검증한 외부 저장소·클라우드 백업·계정·공유 | 권한·재연결·충돌 처리 및 로컬 기능 독립성 확인 |
| 5. 협업·커넥터 | 선택한 실시간 협업·외부 API·AI 기능 | 기능별 실제 동작·권한·취소·오류 확인, 지원 범위와 영상 기록 |
| 6. 생태계·추가 환경 | SDK·템플릿·마켓플레이스·추가 기기 | 공개 전 심사·호환 태그 운영, 실제 검증한 기기·버전 범위만 제공 |

각 단계의 범위는 사용성·데이터 보존·플랫폼 검증 결과로 조정한다. 에디터의 모든 문법·고급 표가 끝날 때까지 앱 검증을 미루지 않고 프레임워크의 정적 사이트 개발도 별도 로드맵으로 진행한다.

## 4. 보류·기술 검증 후보

- 전체 IDE 수준의 터미널·디버거·컨테이너·실행 가능한 노트북·테스트 러너
- 광범위한 외부 서비스·플랫폼·포맷의 일괄 호환
- 고급 손글씨·수식·다이어그램 인식, AR 주석, 고급 PDF OCR
- 자체 AI, 대규모 개인화, 기업 통합 검색
- SSO·SCIM·감사 로그·고급 관리자 콘솔
- Windows·macOS 앱과 Linux·추가 CPU 환경 지원
- 광범위한 기기 간 자동 전환·OS 통합·대규모 멀티디바이스 최적화

후보를 채택하면 해당 기능 기준 문서와 검증 범위를 함께 갱신한다. 기존 비전 전체가 초기 필수 기능이 되지 않도록 관리한다.

## 5. 검증·완료 판단

문서 편집·필기·저장·복원, 가져오기·내보내기의 손실 범위, 플랫폼별 확장 동작과 미지원 데이터 보존을 확인한다. 로컬 기능과 온라인 기능, 정적 게시와 동적 협업을 구분하여 검증한다.

기기와 기록 양식은 [테스트 환경](../테스트%20기기.md), 플랫폼 태그와 테스트 녹화·영상 편집·심사는 [공통 정책](../Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다. 검증하지 않은 환경을 지원 완료로 표시하지 않는다.
