# DocuVerse 개발 문서 안내

현재 문서는 기획·설계 단계의 요구사항을 정리한다. 지원 목표와 실제 구현·검증 완료 상태를 구분하며, 아래 설명만으로 기능 출시나 플랫폼 호환을 주장하지 않는다.

## 1. 프로젝트 공통 방향

- 결과물은 독립 에디터 라이브러리, iPadOS·Android 태블릿 우선 공식 앱, 셀프호스팅 문서 프레임워크·라이브러리다.
- 문서 모델·파서·변환·재사용 로직은 공유하고 UI·입력·저장소·인증·사이트 실행은 각 제품과 어댑터에서 담당한다.
- Windows·macOS 앱 제공 여부는 미정이다. Linux·스마트폰 등 추가 환경도 후속 검토 대상이며 웹 지원이 데스크톱 앱 출시를 의미하지 않는다.
- 프레임워크는 첫 구동 시 동적 기능 ON/OFF를 선택한다. OFF에서는 정적 기능·정적 대체만 제공하며 나머지 동적 실행은 중단한다. 앱의 로컬 편집·저장·필기는 별도 기능이다.
- 플러그인은 검증한 플랫폼·버전·기능·실행 모드 범위만 호환으로 표시한다. 플랫폼별 테스트 영상 제출과 공개 전 심사 기준을 적용한다.
- 구체적인 기반 기술·네이티브/WebView 구현·정식 패키지 이름은 기술 검증 후 확정한다. 코드·명령·패키지 예시는 설계 예시이며 배포된 API가 아니다.
- 개발 기간·가격·사용량 수치는 확정 계획과 구분한다. 모든 기능·문법·플랫폼의 완전한 호환이나 손실 없는 변환을 일괄 보장하지 않는다.

제품 정의의 상세 기준은 [프레임워크 제품 개요](Framework/00_overview.md), 실행·호환·영상 심사 기준은 [공통 정책](Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다.

개발을 시작할 때는 [전체 통합 로드맵](ROADMAP.md)에서 공통 기반 → 실제 환경 검증 → 앱·정적 프레임워크 분기 → 선택형 동적 기능·생태계의 순서와 선행 조건을 먼저 확인한다. 제품별 로드맵은 해당 제품의 상세 작업과 완료 기준을 담당한다.

## 3. 라이선스 문서 상태

현재 저장소의 [LICENSE](../LICENSE)는 GPL-3.0이다. 공식 앱은 기존 GPL-3.0 방향을 유지하며, 에디터의 MIT 배포는 기존 기획상의 목표다. 이 저장소에 별도 에디터 MIT 라이선스가 적용되었다고 표시하지 않는다. 프레임워크와 관련 패키지의 라이선스는 미정이며, 패키지별 배포 범위·라이선스 파일을 출시 전에 확정한다. 이번 문서 정리에서 LICENSE 원문을 변경하지 않는다.
