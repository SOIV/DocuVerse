## 1. 프로그램 기획 및 목적

### 프로그램 개발 방향성
이 프로그램은 앞서 설계한 문서 시스템 라이브러리를 기반으로 하되, Obsidian과 같은 지식 관리 도구및 Notion, GoodNotes/Notability와 같은 노트앱의 장점을 결합한 데스크톱/웹 애플리케이션입니다.<br>
노션의 사용성과 VSCode의 직관적인 인터페이스와 너무 심풀하지 않은 디자인 차용하여 사용자 친화적인 환경을 제공하는 것이 목표입니다.<br>
조금 더 직관적으로 보자면 '하이브리드 노트앱'이라고 보는 정도로 환경을 제공하고 크로스 플렛폼으로서 모든 애플리케이션에서 동일하게 기능을 사용하고 확장을 해나가는 서비스를 하고자 하는 것이 최대 목표이다.

사용되는 라이센스 : GPL-3.0 license

### 서비스 정의 및 포지셔닝
DocuVerse는 Notion의 구조화된 문서/블록 시스템과 GoodNotes/Notability 계열의 자유로운 필기 및 시각적 노트 경험 사이에 있는 하이브리드 지식 작업 앱을 지향한다. 여기에 Obsidian식 로컬 파일 기반, 백링크, 지식 연결성을 일부 결합한다.

핵심 포지션은 Notion과 GoodNotes/Notability 계열 필기 앱 사이의 중간 다리 역할이다. 필기 앱 사용자가 아쉬워하는 텍스트 편집과 구조화 기능, Notion 사용자가 아쉬워하는 필기와 직관적인 자유 배치 경험을 하나의 작업 공간에서 제공하는 것이 목표다. Obsidian의 역할은 주력 사용 경험이라기보다 로컬 우선 저장, 문서 연결성, 데이터 이동성에 대한 보조 철학에 가깝다.

주요 차별화 방향은 다음과 같다.
- 텍스트, 필기, 블록, 미디어를 같은 문서 모델 안에서 자연스럽게 다루는 통합 편집 경험
- 로컬 우선 저장과 선택적 클라우드 협업을 결합한 데이터 소유권 중심 구조
- 외부 서비스 위젯, 자동화, 자체 미디어 플레이어를 통한 올인원 작업 환경
- VSCode/Cursor와 연동 가능한 개발자 친화적 문서화 워크플로우

### 주요 목적
- **하이브리드 저장 방식**: 로컬 저장과 클라우드 저장을 병행하여 사용자가 선택할 수 있는 유연성 제공
- **AI 기반 생산성 향상**: 내장 MCP(Multiple Chat Providers)를 통한 AI 활용 기능 제공
- **최적화된 사용자 경험**: Obsidian의 단점을 보완하고 VSCode/노션의 장점을 결합한 직관적인 인터페이스
- **도구 통합**: 문서 작성, 코드 편집, 지식 관리를 하나의 애플리케이션에서 가능하게 함

### 노션 대비 장점
1. **파일 기반 저장**: 로컬 파일 시스템에 저장되어 데이터 소유권 및 이동성 보장
2. **오프라인 우선 접근**: 인터넷 연결 없이도 완전한 기능 사용 가능
3. **확장성**: 플러그인 시스템을 통한 무한 확장 가능성
4. **커스터마이징**: 사용자 정의 테마 및 스타일링 지원
5. **성능**: 서버 지연 없는 빠른 반응성
6. **프라이버시**: 민감한 데이터를 로컬에만 저장 가능

### Obsidian 대비 장점
1. **현대적 UI**: VSCode/노션 스타일의 보다 직관적인 인터페이스와 너무 심풀하지 않는 디자인
2. **통합 AI 지원**: 내장 MCP로 다양한 AI 서비스 활용 가능
3. **향상된 협업**: 클라우드 저장 선택 시 실시간 협업 기능 제공
4. **우수한 표 기능**: 나무위키 스타일과 엑셀의 강력한 표 편집 기능
5. **코드 지원**: 개발자를 위한 향상된 코드 편집 기능
