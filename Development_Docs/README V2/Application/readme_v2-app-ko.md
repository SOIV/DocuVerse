# DocuVerse 공식 태블릿 앱 — 소개 초안

[한국어](readme_v2-app-ko.md) | [English](readme_v2-app.md)

현재는 기획·설계 단계다. 아래 내용은 개발 방향이며 출시·검증 완료 기능을 뜻하지 않는다. 초기 범위는 [앱 로드맵](../../Application/05b_roadmap_and_future.md)을 따른다.

## 제품 방향

DocuVerse는 텍스트·구조화된 블록과 필기·자유 배치 노트를 함께 다루는 하이브리드 노트 앱을 지향한다. iPadOS·Android 태블릿을 우선 대상으로 하며 Windows·macOS 앱 제공 여부는 미정이다. 구체적인 네이티브·WebView 구현 방식은 검증 후 결정한다.

## 먼저 검증하는 경험

- 계정·클라우드 없이 로컬 문서 작성·저장·재열기
- 텍스트·이미지·첨부 자료, 기본 필기·컬러 블록·포스트잇·도형
- 검색·태그·백링크, 기본 설정·테마 및 태블릿 입력·화면 대응
- 원본을 보존하는 가져오기·내보내기와 미지원 블록의 대체 표시

온라인 기능까지 모두 오프라인으로 사용할 수 있다는 의미는 아니다. 클라우드·공유·협업·외부 API·다중 AI 제공자 연동은 선택형 후속 기능이다. 고급 개발 도구와 추가 플랫폼도 별도 검토 대상이다.

## 에디터·프레임워크와의 관계

독립 에디터 라이브러리와 공통 문서 모델을 사용한다. [셀프호스팅 프레임워크](../../Framework/README.md)는 웹 문서·위키 게시를 위한 별도 도구다. 앱 사용에 사이트 운영을 요구하지 않고, 사이트의 동적 OFF는 앱 로컬 편집을 끄지 않는다.

일부 플러그인의 데이터·로직은 앱과 웹에서 재사용할 수 있다. 지원 플랫폼·버전·기능·실행 모드는 실제 테스트와 녹화·공개 전 심사를 통과한 범위에만 표시한다. 자세한 기준은 [공통 정책](../../Framework/1.%20framework-runtime-and-plugin-policy.md)을 따른다.

## 설치·지원 상태

현재 저장소는 설계 문서를 중심으로 하며 앱 설치 파일이나 실행 가능한 npm 명령을 제공하는 단계가 아니다. 번역·지원 버전·설치 안내는 구현·검증 후 실제 제공 범위에 맞춰 작성한다.

## 가격·라이선스
